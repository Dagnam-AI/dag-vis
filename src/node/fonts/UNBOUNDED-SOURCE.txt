Unbounded-Regular.ttf, Unbounded-Medium.ttf and Unbounded-Bold.ttf are static
Latin-subset instances of the variable font published by the Unbounded Project
(SIL OFL 1.1, see OFL-Unbounded.txt). They are not hand-edited.

Recipe (fontTools 4.67.0), used for Medium (W = 500) and Bold (W = 700)
  font = instancer.instantiateVariableFont(TTFont(upstream), {"wght": W},
                                           updateFontNames=True)
  options = subset.Options()
  options.layout_features += ["pnum", "tnum"]
  options.glyph_names = True
  options.name_IDs = [0, 1, 2, 3, 4, 5, 6, 14, 16, 17, 260]
  subsetter = subset.Subsetter(options)
  subsetter.populate(unicodes=<the 226 code points of Unbounded-Regular.ttf>)
  subsetter.subset(font)

Run with W = 400 the recipe gives the same code points and the same advances as
the shipped Unbounded-Regular.ttf, but not the same file: the shipped Regular
was made earlier and also keeps 10 unused *.BRACKET.varAlt01 glyphs (297
glyphs against 287), and it has no nameIDs 16 and 17. Only Medium and Bold are
reproducible from this recipe.

The name table follows the static-font convention: Medium is nameID 1
"Unbounded Medium", 2 "Regular", 16 "Unbounded", 17 "Medium"; Bold is
nameID 1 "Unbounded", 2 "Bold". A renderer therefore sees one family
"Unbounded" with usWeightClass 400, 500 and 700.

The advance tables in src/brand/unbounded*-metrics.ts are generated from these
files by scripts/gen-font-metrics.mjs.
